Прогони pre-delivery чеклист по всему проекту.

Проверь каждый пункт и выведи результат в виде таблицы: ✅ / ❌ / ⚠️

## Типографика
- Нет запрещённых шрифтов (Inter, Roboto, Arial, Helvetica, Open Sans, Lato)
- Есть чёткая иерархия: display + body шрифт
- Body text ≥ 16px, line-height 1.5-1.6
- Заголовки: line-height 1.1-1.2, tracking-tight
- Длина строки текста ≤ 65ch (max-w-prose)

## Цвет
- Нет чистого чёрного (#000000, bg-black)
- Контраст текста ≥ 4.5:1 (WCAG AA)
- Есть единая цветовая система (токены, не хардкод hex)
- Dark mode реализован или явно помечен как light-only

## Layout
- Нет трёх одинаковых карточек в ряд без вариации
- Есть асимметрия — хотя бы один элемент ломает сетку
- Секции: py-24 и больше, не py-4/py-8
- min-h-dvh используется вместо min-h-screen

## Интерактивность
- Hover-состояние на каждом кликабельном элементе
- cursor-pointer на всех интерактивных элементах
- focus-visible:ring на всех интерактивных элементах
- transition-colors duration-200 на кнопках и ссылках

## Контент
- Нет Lorem ipsum и placeholder-текста
- Нет John Doe, Acme Corp, фейковых метрик
- Нет emoji-иконок — только SVG
- Нет AI-клише: Elevate, Seamless, Next-Gen, Revolutionize

## Адаптивность
- Работает на 375px (мобильный)
- Работает на 768px (планшет)
- Работает на 1024px (ноутбук)
- Работает на 1440px (десктоп)
- Нет горизонтального скролла

## Accessibility
- alt-текст на всех изображениях
- Semantic HTML (nav, main, section, article, button)
- Touch targets ≥ 44×44px
- prefers-reduced-motion обработан

## Код
- Нет // ... или /* ... */ вместо реального кода
- Нет // TODO и «rest follows same pattern»
- Все компоненты полностью реализованы
