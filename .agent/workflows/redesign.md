Проведи аудит и редизайн существующего кода сайта.

1. Прочитай весь текущий код в src/.
2. Загрузи .agent/skills/design/references/redesign.md — следуй методологии Scan → Diagnose → Fix.

## Scan
3. Определи: стек, структуру файлов, текущие шрифты, цвета, spacing, анимации.

## Diagnose
4. Проведи аудит по категориям (оцени каждую 1-5):
   - Типографика (шрифты, иерархия, line-height, длина строки)
   - Цвет (палитра, контраст, dark mode)
   - Layout (симметрия, whitespace, grid)
   - Интерактивность (hover, focus, transitions, cursor)
   - Контент (placeholder-ы, AI-клише, emoji-иконки)
   - Компоненты (карточки, состояния, паттерны)

5. Покажи пользователю таблицу результатов. Спроси: «Исправляю всё или есть приоритеты?»

## Fix
6. Жди ответа. Исправляй в порядке приоритета:
   Шрифты → Цвета → Spacing → Hover-состояния → Layout → Компоненты → Анимации.
7. Не меняй стек — работай с тем что есть.
8. После каждого крупного изменения — запись в DEVLOG.md.
9. В конце прогони /check.
