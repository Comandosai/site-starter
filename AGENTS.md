# Site Starter — Шаблон для создания сайтов

Универсальный шаблон проекта с встроенным навыком профессионального дизайна.

## Правила

- Общайся с пользователем на его языке
- Пользователь может быть нетехническим — объясняй просто
- Каждый интерфейс должен выглядеть как работа дизайнера, не AI
- Полные дизайн-инструкции в `.agents/skills/design/SKILL.md`
- После каждого действия — запись в DEVLOG.md
- Перед редактированием файла — проверь STATUS.md на блокировки

## Первый запуск

Если package.json содержит `"name": "site-starter"` — проект не настроен. Запусти визард:

1. Прочитай brief/ и brand/ — если информация заполнена, НЕ задавай вопросы на которые есть ответы
2. Спроси недостающее (по одному, жди ответа):
   - Что за проект? (для кого, зачем) → brief/company.md
   - Тип сайта? (лендинг / SaaS / портфолио / корпоративный / блог / магазин)
   - Какие страницы нужны? → brief/structure.md
   - Стиль дизайна? (1-3 корпоративный, 4-6 современный, 7-8 смелый, 9-10 экспериментальный)
   - Есть brand-ассеты? (логотип, цвета → brand/)
   - Фреймворк? (Next.js / Astro / Vite+React / HTML+Tailwind)
   - Нужны формы, авторизация, API?
3. Покажи сводку, жди подтверждения
4. Сохрани ответы в brief/ (company.md, audience.md, structure.md, content.md, competitors.md, keywords.md)
5. Установи зависимости, создай layout, токены, заглушки страниц
6. Настрой SEO-основу: robots.txt, sitemap.xml, мета-теги, schema markup

Не пиши код до подтверждения.

## Дизайн-правила (всегда)

- Запрещены шрифты: Inter, Roboto, Arial, Helvetica, Open Sans, Lato
- Запрещён чистый чёрный (#000000) — используй zinc-950 или oklch(0.14 ...)
- Запрещены: neon glow, purple-to-blue градиенты, emoji-иконки
- Запрещён placeholder-контент: Lorem ipsum, John Doe, фейковые метрики
- Запрещены сокращения: // ..., /* ... */, // TODO
- Hover + cursor-pointer + focus-visible:ring на каждом кликабельном элементе
- Типографика: 2-3 шрифта, body ≥ 16px, OKLCH цвета, контраст 4.5:1
- Mobile-first: min-h-dvh, секции py-24+, адаптив 375/768/1024/1440px
- Анимации: только transform + opacity, prefers-reduced-motion
- Код всегда полный — никаких placeholder-ов и сокращений

## SEO-правила (при создании страниц)

- Уникальный title (50-60 символов) и meta description (120-155 символов) на каждой странице
- Один H1 на странице, иерархия H1→H2→H3 без пропусков
- Canonical URL на каждой странице
- Schema markup: Organization + WebSite на главной, релевантные типы на внутренних
- Внутренние ссылки: 3-5 на странице с описательными anchor-текстами
- Изображения: описательные alt-тексты, WebP формат, lazy loading ниже fold
- robots.txt, sitemap.xml — настроить при инициализации проекта

## Команды

### «Настрой проект» / «Начни»
Запусти визард для инициализации проекта (см. «Первый запуск» выше).

### «Создай страницу»
Спроси что за страница → следуй .agents/skills/design/SKILL.md → полная реализация → запись в DEVLOG.md

### «Проверь» / «Чеклист»
Аудит: типографика, цвета, layout, интерактивность, контент, адаптивность, accessibility, SEO. Таблица ✅/❌/⚠️.

### «Улучши» / «Редизайн»
Scan → Diagnose → Fix по .agents/skills/design/references/redesign.md

### «Статус»
Что сделано, какие страницы есть, последние записи из DEVLOG.md.

## Структура

```
brief/            — Бриф проекта (компания, аудитория, структура, тексты, референсы)
brand/            — Brand-ассеты (логотип, цвета, brandbook, шрифты)
src/pages/        — Страницы
src/components/   — Компоненты
src/layouts/      — Layouts
src/styles/       — Глобальные стили и токены
src/assets/       — Изображения, шрифты
src/content/      — Контент
public/           — Статические файлы
```

## Стиль кода

- TypeScript strict, 2-space indent, single quotes, semicolons
- Tailwind utility classes
- PascalCase компоненты, camelCase функции, kebab-case файлы
