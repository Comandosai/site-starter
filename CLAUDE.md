# Site Starter — Шаблон для создания сайтов

Универсальный шаблон проекта с встроенным навыком профессионального дизайна. Создаёт красивые, продуманные сайты без типичных AI-клише.

## !! ПЕРВЫЙ ЗАПУСК — РЕЖИМ ВИЗАРДА !!

> Если package.json содержит `"name": "site-starter"` — проект ещё не настроен.
> Твоя задача — задать вопросы и настроить проект.

### Правила визарда:
1. Сначала прочитай brief/ и brand/ — если информация уже заполнена, НЕ задавай вопросы на которые есть ответы
2. НЕ пиши код до завершения визарда
3. Задавай недостающие вопросы ПО ОДНОМУ, жди ответа
4. После сбора ответов — покажи сводку и жди подтверждения

### Источники информации:
- brief/company.md — о компании, миссия, тон коммуникации
- brief/audience.md — целевая аудитория, боли, персоны
- brief/structure.md — структура сайта, страницы, секции
- brief/content.md — тексты, УТП, офферы, FAQ
- brief/competitors.md — конкуренты и позиционирование
- brief/keywords.md — ключевые слова и SEO-цели
- brief/references/ — скриншоты сайтов-примеров
- brand/ — логотип, цвета, brandbook, шрифты

### Вопросы (пропусти если ответ есть в brief/):
1. Что за проект? (для кого, зачем)
2. Тип сайта? (лендинг / SaaS / портфолио / корпоративный / блог / магазин)
3. Какие страницы нужны?
4. Стиль дизайна? (1-3 корпоративный, 4-6 современный, 7-8 смелый, 9-10 экспериментальный)
5. Есть ли brand-ассеты? (логотип, цвета → brand/)
6. Фреймворк? (Next.js / Astro / Vite+React / HTML+Tailwind, рекомендую Next.js)
7. Нужны ли формы, авторизация, API?

После подтверждения: сохрани ответы в brief/, установи зависимости, создай layout, настрой токены, создай заглушки страниц.

## Дизайн-правила (соблюдай ВСЕГДА)

- Каждый интерфейс должен выглядеть так, будто его сделал дизайнер, а не AI
- Запрещены шрифты: Inter, Roboto, Arial, Helvetica, Open Sans, Lato
- Запрещён чистый чёрный (#000000) — используй zinc-950 или oklch(0.14 ...)
- Запрещены: neon glow, purple-to-blue градиенты, emoji-иконки, placeholder-контент
- Запрещены сокращения: // ..., /* ... */, // TODO
- Каждый кликабельный элемент: hover + cursor-pointer + focus-visible:ring-2
- Асимметрия важнее симметрии
- Типографика: 2-3 шрифта, body ≥ 16px, line-height 1.5-1.6
- Цвета: OKLCH, контраст 4.5:1, dominant + accent
- Mobile-first: min-h-dvh, секции py-24+
- Анимации: только transform + opacity, prefers-reduced-motion обязателен
- Код всегда полный, production-ready — никаких placeholder-ов

Полные дизайн-инструкции — в `.agent/skills/design/SKILL.md` и `.agent/skills/design/references/`.

## SEO-правила (при создании страниц)

- Уникальный title (50-60 символов) и meta description (120-155 символов) на каждой странице
- Один H1 на странице, иерархия H1→H2→H3 без пропусков
- Canonical URL на каждой странице
- Schema markup: Organization + WebSite на главной, релевантные типы на внутренних
- Внутренние ссылки: 3-5 на странице с описательными anchor-текстами
- Изображения: описательные alt-тексты, WebP формат, lazy loading ниже fold
- robots.txt, sitemap.xml — настроить при инициализации проекта
- Для AI-поиска (GEO): разрешить GPTBot, ClaudeBot, PerplexityBot в robots.txt


## Команды

### «Начни» / «Настрой проект»
Запусти визард (см. выше).

### «Создай страницу»
1. Спроси что за страница и что на ней
2. Следуй дизайн-правилам из .agent/skills/design/SKILL.md
3. Создай полную реализацию в src/pages/ и src/components/
4. Проверь адаптивность: 375 / 768 / 1024 / 1440px
5. Запиши в DEVLOG.md

### «Проверь» / «Чеклист»
Прогони pre-delivery чеклист: типографика, цвета, layout, интерактивность, контент, адаптивность, accessibility, код. Покажи таблицу ✅/❌/⚠️.

### «Улучши» / «Редизайн»
Проведи аудит по методологии Scan → Diagnose → Fix из .agent/skills/design/references/redesign.md.

### «Статус»
Покажи состояние проекта: что сделано, какие страницы и компоненты есть, последние действия из DEVLOG.md.

## Логирование

- **STATUS.md** — перед редактированием файла проверь блокировки. Добавь свою блокировку перед работой, сними после.
- **DEVLOG.md** — после каждого завершённого действия добавь запись с датой, описанием и списком изменённых файлов.

## Структура проекта

```
brief/            — Бриф проекта (компания, аудитория, структура, тексты, референсы)
brand/            — Brand-ассеты (логотип, цвета, brandbook, шрифты)
src/pages/        — Страницы (file-based routing)
src/components/   — Компоненты
src/layouts/      — Layouts (header, footer, nav)
src/styles/       — Глобальные стили и токены
src/assets/       — Изображения, шрифты
src/content/      — Контент (тексты, данные)
public/           — Статические файлы
```

## Стиль кода

- TypeScript strict, 2-space indent, single quotes, semicolons
- Tailwind utility classes, без CSS modules
- PascalCase компоненты, camelCase функции, kebab-case файлы
- Один компонент на файл, всегда props interface
