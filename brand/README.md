# Brand-ассеты

Положите сюда фирменные материалы вашего проекта. AI-агент будет использовать их при создании сайта.

## Что можно положить

| Файл | Описание |
|------|----------|
| `logo.svg` | Логотип в SVG (рекомендуется) |
| `logo.png` | Логотип в PNG (запасной вариант) |
| `favicon.ico` | Иконка для вкладки браузера |
| `colors.md` | Фирменные цвета |
| `fonts/` | Файлы шрифтов (если не Google Fonts) |
| `brandbook.pdf` | Брендбук / гайдлайн |
| `screenshots/` | Референсы, мокапы, вдохновение |

## Как использовать

1. Положите файлы в эту папку
2. Скажите агенту: «Я добавил brand-ассеты, используй их»
3. Агент интегрирует: скопирует в нужные папки, настроит цвета и шрифты
