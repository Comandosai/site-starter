# Бриф проекта

Эта папка содержит всю информацию о вашем проекте. AI-агент прочитает эти файлы и создаст сайт на их основе.

## Как заполнять

Заполните файлы ниже — можно кратко, можно подробно. Чем больше информации, тем точнее результат.

Не обязательно заполнять всё — заполните что знаете, остальное агент спросит.

| Файл | Что писать |
|------|-----------|
| `company.md` | О компании: чем занимается, миссия, ценности, история |
| `audience.md` | Целевая аудитория: кто ваши клиенты, их боли и потребности |
| `structure.md` | Структура сайта: какие страницы, какие секции на каждой |
| `content.md` | Тексты: заголовки, описания, УТП, офферы, FAQ |
| `competitors.md` | Конкуренты: кто они, чем отличаетесь, позиционирование |
| `keywords.md` | Ключевые слова: по каким запросам вас должны находить |
| `references/` | Скриншоты сайтов которые нравятся, примеры стиля |

## Для AI-агента

При начале работы над проектом:
1. Прочитай все файлы в brief/ — это основа для принятия решений
2. Если файл пустой (только шаблон) — спроси пользователя
3. Используй информацию из brief/ для генерации реального контента, не placeholder-ов
4. Если в references/ есть скриншоты — проанализируй стиль и учти при дизайне
