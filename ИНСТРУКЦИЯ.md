# Site Starter — Инструкция

Шаблон для создания профессиональных сайтов с помощью AI-агента. Работает в Google Antigravity, Claude Code и OpenAI Codex.

Встроенные навыки дизайна и SEO обеспечивают качество на уровне агентства: правильная типографика, цвета, анимации, адаптивность, поисковая оптимизация — без типичных AI-клише.

---

## Что нужно для работы

1. **Компьютер** с macOS, Windows или Linux
2. **Интернет**
3. **Node.js** версии 18+ (скачать: https://nodejs.org)
4. **AI-среда** — одна из:
   - Google Antigravity (рекомендуется — поддерживает /команды)
   - Claude Code (терминал)
   - OpenAI Codex

---

## Шаг 1. Заполните бриф

1. Скопируйте эту папку и переименуйте под ваш проект
2. Заполните бриф (чем больше — тем точнее результат):
   - `brief/company.md` — о компании: чем занимается, миссия, тон общения
   - `brief/audience.md` — целевая аудитория: кто клиенты, их боли
   - `brief/structure.md` — какие страницы нужны, какие секции на каждой
   - `brief/content.md` — тексты: заголовки, описания, УТП, FAQ
   - `brief/competitors.md` — конкуренты: кто они, чем вы отличаетесь
   - `brief/keywords.md` — по каким запросам вас должны находить в поиске
   - `brief/references/` — скриншоты сайтов которые нравятся
3. Если есть логотип, фирменные цвета, brandbook — положите в `brand/`

> Можно не заполнять ничего — агент задаст вопросы сам. Но заполненный бриф экономит время.

---

## Шаг 2. Откройте проект и настройте

### Вариант A: Google Antigravity (рекомендуется)
1. Откройте Antigravity
2. Откройте папку проекта
3. В чате напишите `/start` или «Настрой проект»
4. Отвечайте на вопросы визарда

### Вариант B: Claude Code
1. Откройте терминал
2. Перейдите в папку проекта: `cd путь/к/папке`
3. Запустите: `claude`
4. Напишите: «Настрой проект»
5. Отвечайте на вопросы

### Вариант C: OpenAI Codex
1. Откройте проект в среде с Codex
2. Напишите: «Настрой проект»
3. Отвечайте на вопросы

---

## Шаг 3. Работайте с сайтом

Просто пишите что хотите сделать:

- «Создай главную страницу»
- «Добавь страницу О нас»
- «Сделай секцию с ценами»
- «Добавь анимации при скролле»
- «Улучши дизайн»

AI-агент автоматически применяет профессиональные правила дизайна.

---

## Команды

### Быстрые команды (Antigravity)
| Команда | Что делает |
|---------|-----------|
| `/start` | Настройка нового проекта (визард) |
| `/new-page` | Создание новой страницы |
| `/redesign` | Аудит и улучшение дизайна |
| `/check` | Проверка качества (чеклист) |
| `/status` | Текущее состояние проекта |

### Текстовые команды (любая среда)
| Команда | Что делает |
|---------|-----------|
| «Настрой проект» | Визард настройки |
| «Создай страницу» | Новая страница |
| «Улучши» / «Редизайн» | Аудит и улучшение |
| «Проверь» / «Чеклист» | Проверка качества |
| «Статус» | Состояние проекта |

---

## Работа несколькими агентами

Если вы переключаетесь между Antigravity, Claude Code и Codex — они не потеряют контекст:

- **DEVLOG.md** — каждый агент записывает что сделал
- **STATUS.md** — агенты видят кто сейчас работает с каким файлом

Перед началом работы в новом агенте скажите: «Статус» — он прочитает журнал и поймёт что происходит.

## Структура проекта

```
brief/            — Бриф проекта (компания, аудитория, структура, тексты, референсы)
brand/            — Логотип, цвета, brandbook, шрифты
src/
  pages/          — Страницы сайта
  components/     — Переиспользуемые компоненты
  layouts/        — Общая структура (header, footer)
  styles/         — Стили и дизайн-токены
  assets/         — Изображения, шрифты
  content/        — Тексты и данные
public/           — Статические файлы
```

## Устранение проблем

| Проблема | Решение |
|----------|---------|
| Агент не задаёт вопросы | Напишите «Настрой проект» или «/start» |
| Ошибка npm install | Проверьте что Node.js 18+ установлен: `node --version` |
| Агент не знает что сделано | Напишите «Статус» — он прочитает DEVLOG.md |
| Дизайн выглядит generic | Напишите «Проверь» — агент проведёт аудит и исправит |
| Нужно сменить агента | Просто откройте проект в другой среде и скажите «Статус» |
